Problem

A stack that didn't talk to itself

Ad data in one place, site analytics in another, orders in a third, reconciled by hand. Everything downstream was manual too: analyzing creative, deciding what to do about it, building the page, then writing the report about all of it. That list is roughly what a performance agency sells you as a retainer, and most of it is repetitive enough for a system to handle.

Architecture

Four layers

Data

Scheduled ingestion of ad, analytics and order data, with a reconciliation step that makes them agree before anything reads them.

Workers

Separate workspaces each doing one job, instead of one assistant asked to do everything. Narrow scope keeps output reviewable.

Pipeline

The overnight run, with thresholds it has to clear and a dry-run option at every stage that writes.

Review

A Kanban board where recommendations wait for a person, plus automated reporting.

Signal Reader

Surfaces friction candidates from funnel behavior.

Angle Classifier

Works out which promise is landing.

Page Composer

Writes to documented style rules.

Offer Mapper

Maps offer structure and post-purchase path.

Measurement Guard

Checks tracking before a result is trusted.

Digest Writer

Handles the recurring reporting.

The rule

Copy automates. Layout doesn't.

Copy can be generated against written voice rules. Layout and structure can't. That rule lives in how the pipeline branches, not in a prompt asking nicely.

Deciding where that line sits took longer than building either side of it. Everything that writes has a dry-run path, a threshold to clear, and somewhere a person can say no.
