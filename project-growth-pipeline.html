Creative-to-Page
Alignment Pipeline

Ad creative changed every week. The landing pages didn't. I built a system that runs overnight and fixes that.

Client
DTC Supplement Brand
Role
Architect & Sole Builder
Stack
React · Express · Meta API · GA4
Status
In Production
Problem

Winning ads pointed at the wrong page

A creative would start winning on one angle and send everyone to a page written for a different one. Fixing it meant doing the analysis by hand, so it happened rarely. Google and Microsoft also fold landing page relevance into Quality Score, so a mismatched page costs you on conversion rate and again on cost per click.

What it does

Five steps, every night

01

Consolidate

Pulls ad performance, site analytics and order data into one place and makes them agree. I built this first, because the three systems had never matched.

02

Analyze

Works out which creatives are winning and which angle is doing the work.

03

Decide

Picks one of three options. There's no default branch, and stopping counts as a decision.

Inline test

Aligned variant on the existing page, run as an A/B test.

Full rebuild

A new landing page built off the brand system.

Escalate

Not enough confidence, or it's a layout call I want to make.

04

Generate

Builds the page against design tokens, known platform quirks, patterns that already tested well, and written voice rules.

05

Review

Everything lands on a Kanban board for a person. Results feed the next run.

Guardrails

Why it's usable

ThresholdsWon't touch a campaign below a spend floor or without enough days behind it.
Dry-runEvery output can be inspected before it's real.
DedupeWon't re-recommend what it already recommended.
Copy yes, layout noCopy automates against voice rules. Structure doesn't. That's in the branching, not a prompt.

The one thing I didn't automate was media buying. Someone still has to be in the accounts. Everything after that decision, the system handles.

For context: FERMÀT has raised roughly $74M productizing this category for DTC brands, sold on revenue share. Mine works off creative performance rather than ad intent, and runs on infrastructure the brand owns.
